# 요구사항 (Requirements)

> **무엇을, 왜 만드는지** 정의하는 문서입니다. 기술적인 구현 방법은 `design.md`에 적습니다.
> 마지막 수정: 2026-11-16
> 기준 시안: Figma `기획 인수인계: 03-러너블-상세디자인-v1.1-211108` (VINYL C, 2021.10)

---

## 1. 목표

- **문제**: 러너블(러닝·레이스 대회 앱)의 상세 디자인은 Figma 시안으로만 있어서, 실제 화면 마크업과 스타일을 확인하거나 개발에 넘길 수 있는 결과물이 없다.
- **해결**: Figma 시안의 모바일 화면을 React + TypeScript로 퍼블리싱하고, 화면 목록과 진행 상태를 IA 페이지(`/ia`)에서 관리한다.
- **성공 기준**:
  - 4장 페이지 목록 중 `필수` 화면이 Figma 시안과 같은 레이아웃·문구·색상으로 구현된다.
  - 시안에 있는 상태별 화면(기본, 입력 전/후, 에러, 노데이터 등)을 화면 안에서 재현할 수 있다.
  - 모든 화면이 `/ia`에 등록되고, `/ia`에서 `/guide`로 이동할 수 있다.
  - `npm run build`가 통과한다.

## 2. 범위

### 포함 (이번에 만드는 것)
- **ME 회원**: 로그인, 비밀번호 재설정, 회원가입(이메일 인증, 약관 동의, 추가 정보, 가입 완료)
- **MY 홈/마이**: 스플래시, 홈, 내 정보(인증·트레이닝·대회 기록), 프로필 수정, 설정, 회원 탈퇴, 무료 참가권, 기록 보기·공유·제출, 알림
- **RA 레이스**: 대회 목록, 대회 소개(탭 4개), 참가 신청 6단계, 참가 신청 조회·수정·취소
- **TR 트래커**: 트래커 메인, 카운트다운, 기록 중·정지 화면(일반/대회), 베타 테스트 의견 접수
- **CO 공통**: 웹페이지 에러, 로딩, 약관 폼, 공통 팝업(확인·안내)
- **CO 이메일 템플릿**: 이메일 컨펌, 회원가입 완료, 비밀번호 재설정, 관리자 승인요청·승인완료·비번재설정, 1:1 문의 답변 (React 밖 정적 이메일 HTML)
- **관리 화면**: `/ia`, `/guide`
- **플랫폼별 화면**: 시안에 iOS / AOS가 구분된 화면은 두 버전 모두 구현

### 제외 (이번에 안 만드는 것)
- 실제 로그인·회원가입·SNS 로그인 연동
- 실제 결제(신용카드, 가상계좌) 처리
- GPS 위치 추적, 실제 지도 API 연동 (지도 영역은 시안 이미지로 대체)
- 사진 촬영·저장, 공유 시트 등 기기 기능 연동
- 푸시 알림 발송
- 관리자 기능
- `로고&앱스토어` 페이지의 앱 아이콘·스토어 스크린샷 (퍼블리싱 대상 아님)

## 3. 사용자 스토리

`[사용자]로서, [목적]을 위해 [기능]을 원한다` 형식으로 적습니다.
수용 기준(Acceptance Criteria)은 **WHEN ~ THEN ~** 형식으로 적어 완료 여부를 판단할 수 있게 합니다.

### US-01. 로그인 (ME1)
**회원으로서**, 서비스를 이용하기 위해, 이메일 또는 SNS 계정으로 로그인하고 싶다.

- [ ] WHEN 로그인 화면에 접속하면 THEN 이메일·비밀번호 입력란, 로그인 버튼, SNS 로그인 버튼, 비밀번호 재설정·회원가입 링크가 보인다
- [ ] WHEN 입력값이 잘못된 상태로 로그인하면 THEN 시안(`ME1-로그인_02에러`)과 같은 에러 메시지가 표시된다
- [ ] WHEN 이전 접속 기록이 있으면 THEN 시안(`ME1-로그인_03접속기록`)과 같은 최근 로그인 표시가 보인다
- [ ] WHEN iOS / AOS 화면을 비교하면 THEN 시안의 플랫폼별 차이(`_01기본(iOS)`, `_01기본(AOS)`)가 반영되어 있다

### US-02. 비밀번호 재설정 (ME1.1 ~ ME1.4)
**비밀번호를 잊은 회원으로서**, 다시 로그인하기 위해, 비밀번호를 재설정하고 싶다.

- [ ] WHEN 재설정 정보를 입력하기 전이면 THEN 다음 버튼이 비활성 상태다
- [ ] WHEN 정보를 입력하고 다음을 누르면 THEN 재설정 이메일 전송 안내 화면(ME1.2)으로 이동한다
- [ ] WHEN 새 비밀번호를 입력 완료하면 THEN 재설정 완료 화면(ME1.4)으로 이동한다

### US-03. 회원가입 (ME2 ~ ME2.4)
**신규 사용자로서**, 서비스를 이용하기 위해, 이메일로 가입하고 약관에 동의하고 싶다.

- [ ] WHEN 이메일을 입력하고 인증을 요청하면 THEN 인증번호 입력 상태(`ME2-회원가입_02인증번호`)가 표시된다
- [ ] WHEN 약관 항목을 누르면 THEN 해당 약관 상세(서비스 이용약관, 개인정보 처리방침, 위치 정보, 마케팅 수신)가 열린다
- [ ] WHEN 필수 약관에 모두 동의하지 않으면 THEN 다음 단계로 진행할 수 없다
- [ ] WHEN 가입을 마치면 THEN 가입 완료 화면(ME2.4)이 단계별로 표시된다

### US-04. 홈과 내 정보 (MY1 ~ MY3.1)
**회원으로서**, 내 러닝 현황을 한눈에 보기 위해, 홈과 내 정보 화면을 확인하고 싶다.

- [ ] WHEN 앱에 진입하면 THEN 스플래시(MY1)가 표시된 뒤 홈으로 이동한다
- [ ] WHEN 홈 콘텐츠 양이 다르면 THEN 최소·최대 케이스(`MY3-홈_01최소`, `_02최대`) 모두 레이아웃이 깨지지 않는다
- [ ] WHEN 내 정보에서 인증·트레이닝·대회 기록 영역을 보면 THEN 데이터 유무에 따라 노데이터 화면 또는 목록이 표시된다

### US-05. 설정과 계정 관리 (MY3.1.1 ~ MY3.1.2.8)
**회원으로서**, 내 계정을 관리하기 위해, 프로필 수정·알림 설정·탈퇴·무료 참가권 등록을 하고 싶다.

- [ ] WHEN 프로필을 수정하고 저장하면 THEN 저장 확인 팝업이 표시된다
- [ ] WHEN 마케팅·위치기반·푸시 알림 설정을 바꾸면 THEN On/Off에 맞는 변경 안내 팝업이 표시된다
- [ ] WHEN 로그아웃 또는 회원 탈퇴를 누르면 THEN 확인 팝업이 표시되고, 탈퇴는 동의 체크 후에만 진행된다
- [ ] WHEN 무료 참가권 코드를 입력하면 THEN 입력 전·에러·중복 쿠폰·등록 완료 상태가 시안과 같이 표시된다

### US-06. 기록 보기·공유·제출 (MY3.1.3 ~ MY3.1.7)
**러너로서**, 내 기록을 확인하고 대회에 인정받기 위해, 기록을 보고 공유하고 제출하고 싶다.

- [ ] WHEN 전체 기록 보기에 들어가면 THEN 기록이 있으면 목록, 없으면 노데이터 화면이 표시된다
- [ ] WHEN 트레이닝 기록 상세에서 공유를 누르면 THEN 기록 공유·인증샷 공유 화면으로 이동한다
- [ ] WHEN 대회 기록 제출을 진행하면 THEN 대회 선택 → 이미지 제출 → 확인 → 완료 순서로 화면이 이어진다
- [ ] WHEN 알림 화면에 들어가면 THEN 알림이 있으면 목록, 없으면 노데이터 화면이 표시된다

### US-07. 대회 탐색 (RA1 ~ RA2.3.3)
**러너로서**, 참가할 대회를 고르기 위해, 대회 목록과 상세 정보를 보고 싶다.

- [ ] WHEN 대회 목록에 접속하면 THEN 대회 카드 목록이 표시된다
- [ ] WHEN 대회 소개의 탭(대회개요, 참가방법, 레이스팩, 공지·FAQ)을 누르면 THEN 해당 탭 내용으로 바뀐다
- [ ] WHEN 대회 소개 화면을 스크롤하면 THEN 시안(`RA2-대회 소개_02스크롤`)과 같이 상단 영역이 바뀐다
- [ ] WHEN 사이즈 조견표·상세 이미지·공지·FAQ를 누르면 THEN 각 상세 화면이 열린다
- [ ] WHEN 1:1 문의를 작성해 제출하면 THEN 작성 완료 화면이 표시된다

### US-08. 대회 참가 신청 (RA3 ~ RA3.6)
**러너로서**, 대회에 참가하기 위해, 단계별로 신청 정보를 입력하고 싶다.

- [ ] WHEN 참가 신청을 시작하면 THEN 약관 동의 → 개인정보 → 대회 정보 → 보험 가입 → 결제 정보 → 최종 확인의 6단계로 진행된다
- [ ] WHEN 참여 연령이 아니면 THEN 연령 안내(RA3.1.1)가 표시된다
- [ ] WHEN 결제 수단(신용카드, 가상계좌, 무료참가권)을 고르면 THEN 결제 정보·최종 확인·신청 완료 화면이 수단별로 다르게 표시된다 (목업 처리)

### US-09. 참가 신청 조회·변경 (RA4 ~ RA4.5)
**신청한 러너로서**, 신청 내역을 관리하기 위해, 조회·사이즈 수정·공유·취소를 하고 싶다.

- [ ] WHEN 참가 신청 조회에 들어가면 THEN 결제 수단별 신청 내역이 표시된다
- [ ] WHEN 기념품 사이즈 수정을 누르면 THEN 사이즈 선택 화면이 열린다
- [ ] WHEN 신청 취소를 누르면 THEN 취소 확인 팝업 → 취소 완료 화면으로 이어진다

### US-10. 트래커 (TR1 ~ TR2.1)
**러너로서**, 달리기를 기록하기 위해, 트래커로 트레이닝 또는 대회 기록을 측정하고 싶다.

- [ ] WHEN 트래커 메인에 처음 들어가면 THEN 코치마크가 표시된다 (대회 있음·없음 케이스 각각)
- [ ] WHEN 위치 정보 동의 또는 위치 서비스 설정이 필요하면 THEN 안내 팝업(TR1.1.1, TR1.1.2)이 표시된다
- [ ] WHEN 기록을 시작하면 THEN 5 → 1 카운트다운 후 기록 화면(거리, 페이스, 시간)으로 바뀐다 (목업 값)
- [ ] WHEN 기록 중 정지하면 THEN 정지 상태 화면과 기록 저장 알림(TR1.4)이 표시된다
- [ ] WHEN 베타 테스트 의견을 제출하면 THEN 접수 완료 화면이 표시된다

### US-11. 공통 화면 (CO)
**사용자로서**, 오류나 대기 상황을 이해하기 위해, 공통 안내 화면을 보고 싶다.

- [ ] WHEN 웹페이지를 불러오지 못하면 THEN 웹페이지 에러 화면(CO2.5)이 표시된다
- [ ] WHEN 데이터를 불러오는 중이면 THEN 로딩 표시가 보인다
- [ ] WHEN 약관 폼을 열면 THEN 시안의 약관 폼 레이아웃으로 표시된다
- [ ] WHEN 이메일 템플릿 HTML(`public/email/*.html`)을 메일 클라이언트에서 열면 THEN 시안(CO3 ~ CO3.9)과 같은 레이아웃으로 표시된다

## 5. 비기능 요구사항

- **대상 기기**: 모바일 앱 화면 기준. Figma 시안 프레임 너비는 **360px**이다. 웹뷰 안에서 쓰이는 것을 전제로 한다.
- **반응형**: 모바일(360px~) 기준으로 구현하고, 태블릿(768px~)·데스크톱(1024px~)에서는 **화면 너비에 맞게 늘린다** (너비 100%). 카드 목록 등 반복 영역은 768px·1024px에서 열 수를 늘리고, 세부 배치는 `design.md`에 정한다.
- **폰트**: Noto Sans KR (시안 텍스트 스타일 예: `Noto/Headline/H1` 24px / 32px / Bold)
- **공통 레이아웃**: 시안 컴포넌트 `Top Bar`(상단 바), `Bottom Bar`(하단 탭바: 홈, 레이스, 트래커)를 사용한다. 화면별 표시 여부는 `design.md`에 정한다.
- **브라우저**: 최신 Chrome, Safari, Edge, Samsung Browser, iOS·Android 웹뷰
- **접근성**: 이미지 `alt` 필수, 버튼과 링크는 키보드로 접근 가능, 아이콘 버튼은 `aria-label` 제공
- **에셋**: 아이콘·이미지는 Figma 원본 에셋을 사용한다 (`AGENTS.md` 5.4)
- **성능**: 이미지는 적절한 크기로 최적화, 첫 화면 3초 이내 로딩
